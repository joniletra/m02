### EX01 — Seletores CSS

**Nível:** L1

Neste exercício foram aplicados diferentes seletores CSS a uma página HTML existente, sem alterar a sua estrutura.

Foram utilizados seletores de elementos, classes, IDs, descendentes e atributos. Também foram aplicadas as pseudo-classes `hover` e `focus` para alterar os estilos durante a interação do utilizador.

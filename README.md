# Módulo 02 - CSS3, Flexbox e Grid

Este repositório contém os 9 exercícios práticos do Módulo 02 da unidade curricular de Programação Web.

Os exercícios têm como objetivo aplicar estilos CSS, compreender o Box Model, trabalhar com Flexbox e CSS Grid e desenvolver páginas responsivas utilizando HTML5 e CSS3.

---

## Exercícios Realizados

- **ex01** — Seletores CSS (Nível L1)
- **ex02** — Box Model (Nível L1)
- **ex03** — Typography (Nível L2)
- **ex04** — Components (Nível L2)
- **ex05** — Flexbox Playground (Nível L1)
- **ex06** — Navigation Bar (Nível L2)
- **ex07** — Photo Gallery (Nível L2)

### ex01 — Seletores CSS

- **Seletores de Elementos:** Utilização do seletor `h1` para alterar a cor e o alinhamento do título.
- **Classes e IDs:** Aplicação de `.destaque` para destacar texto e `#nome` para personalizar um campo do formulário.
- **Seletores Descendentes e de Atributos:** Utilização de `nav a` para estilizar os links do menu e `input[type="email"]` para alterar o fundo do campo Email.
- **Pseudo-classes:** Utilização de `:hover` e `:focus` para alterar os estilos durante a interação do utilizador.

### ex02 — Box Model

- **Criação de Cartões:** Desenvolvimento de três cartões com a mesma classe CSS.
- **Dimensões e Espaçamentos:** Utilização de `width`, `padding`, `border` e `margin` para controlar o tamanho e os espaços dos cartões.
- **Box Sizing:** Aplicação de `box-sizing: border-box` para incluir o padding e a borda na largura definida.

### ex03 — Typography

- **Documentação Técnica:** Criação de uma página simples com informações sobre HTML e CSS.
- **Tipografia:** Utilização de `font-family`, `font-size`, `line-height` e `font-weight` para definir o aspeto dos textos.
- **Cores e Fundos:** Aplicação de `color` e `background-color` para melhorar a apresentação da página.
- **Títulos e Links:** Personalização dos elementos `h1`, `h2`, `h3` e das hiperligações.

### ex04 — Components

- **Cards:** Criação de cartões reutilizáveis com fundo, borda e espaçamento.
- **Buttons:** Definição de uma classe CSS para aplicar o mesmo estilo a diferentes botões.
- **Alerts e Badges:** Criação de mensagens de alerta e pequenas etiquetas visuais.
- **Forms:** Construção de um formulário simples com campos de nome e email.
- **Reutilização:** Utilização de classes CSS para manter estilos consistentes entre componentes.

### ex05 — Flexbox Playground

- **Flex Direction:** Criação de layouts horizontais e verticais utilizando `flex-direction`.
- **Alinhamento:** Utilização de `justify-content` e `align-items` para posicionar os elementos.
- **Espaçamento:** Aplicação de `gap` para definir a distância entre os elementos.
- **Flexibilidade:** Experimentação de `flex-wrap`, `flex-grow` e `flex-shrink` para controlar o comportamento dos elementos.
- **Layouts:** Desenvolvimento de cinco exemplos diferentes utilizando Flexbox.

### ex06 — Navigation Bar

- **Barra de Navegação:** Criação de uma barra com logótipo em texto, links e botão.
- **Flexbox:** Utilização de `display: flex`, `justify-content` e `align-items` para organizar os elementos.
- **Responsividade:** Aplicação de `flex-wrap` para permitir que os elementos mudem de linha em ecrãs mais pequenos.

### ex07 — Photo Gallery

- **CSS Grid:** Criação de uma galeria de fotografias organizada em três colunas.
- **Espaçamento:** Utilização de `gap` para separar as imagens.
- **Imagens Responsivas:** Aplicação de `width: 100%` e `object-fit: cover` para adaptar as fotografias ao espaço disponível.
- **Diferentes Tamanhos:** Utilização de `grid-column: span 2` para criar uma fotografia que ocupa duas colunas.
- **Imagens Locais:** Organização de cinco fotografias escolhidas pelo aluno numa pasta `imagens/`.
- **Media Queries:** Adaptação da galeria para uma coluna em ecrãs pequenos.

### ex08 — Dashboard

- **Estrutura Principal:** Desenvolvimento de um dashboard com `header`, `sidebar`, `main` e `footer`.
- **CSS Grid:** Utilização de `grid-template-columns`, `grid-template-areas` e `grid-area` para organizar as diferentes secções.
- **Cards:** Criação de três cartões com dados demonstrativos sobre alunos, turmas e disciplinas.
- **Tabela:** Construção de uma tabela HTML para apresentar informações sobre alunos e notas.
- **Responsividade:** Utilização de uma media query para adaptar a estrutura a ecrãs pequenos.

### ex09 — Responsive Challenge

- **Landing Page:** Criação de uma página de apresentação de serviços de tecnologia.
- **Mobile First:** Desenvolvimento inicial dos estilos para dispositivos móveis, adaptando posteriormente a página a ecrãs maiores.
- **Media Queries:** Utilização de `min-width` para definir diferentes layouts a partir de 768px, 1024px e 1440px.
- **CSS Grid:** Organização dos cartões de serviços em uma, duas ou três colunas, conforme a largura do ecrã.
- **Flexbox:** Utilização de Flexbox para organizar a navegação.
- **Adaptação de Conteúdo:** Aplicação de `max-width` e `box-sizing: border-box` para controlar as dimensões dos elementos e evitar que ultrapassem a largura disponível.
- **Resoluções:** Página preparada para funcionar nas larguras de 320px, 768px, 1024px e 1440px, sem necessidade de frameworks.

## Tecnologias Utilizadas

- **HTML5** — Estruturação das páginas.
- **CSS3** — Estilização dos elementos.
- **Flexbox** — Organização e alinhamento de componentes.
- **CSS Grid** — Criação de layouts com linhas e colunas.
- **Media Queries** — Adaptação das páginas a diferentes dimensões de ecrã.

Todos os exercícios foram desenvolvidos sem recurso a frameworks CSS, como Bootstrap ou Tailwind.

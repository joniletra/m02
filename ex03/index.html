Introdução ao HTML e CSS

1. O que é HTML?

HTML é uma linguagem de marcação utilizada para estruturar o conteúdo de páginas web.

2. O que é CSS?

CSS é utilizado para definir o aspeto visual das páginas, como cores, fontes e tamanhos.

3. Diferença entre HTML e CSS

O HTML define a estrutura da página, enquanto o CSS define a sua apresentação.
